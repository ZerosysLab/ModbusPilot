# 专栏总名称：《工控自动化全景图：从底层设备到工业 4.0 的进阶之路》

### 🏭 第一系列：工控自动化之“底层设备与数据源头”
*核心定位：按典型工业场景划分，盘点数据是怎么产生的，物理量如何变成电信号。*

*   **第01篇：《流程工业的“五官”：化工与水处理行业的核心传感器盘点》**
    *   **内容**：聚焦连续性生产。详解温度（热电偶/PT100）、压力/液位变送器、电磁/涡街流量计。讲解为什么流程行业最依赖 4-20mA 模拟量，以及防爆（本安型/隔爆型）的基础概念。
*   **第02篇：《离散制造的“触觉”：3C、汽车与包装产线上的检测与开关》**
    *   **内容**：聚焦计件与位移生产。详解光电开关、接近开关、行程开关的作用。科普 NPN/PNP 漏型与源型的区别，以及它们如何向控制系统输出高频的 0/1 脉冲。
*   **第03篇：《动力与传动车间的“肌肉”：让设备动起来的控制单元》**
    *   **内容**：聚焦运动执行。详解变频器（控制速度）、伺服电机系统（精准定位）以及编码器（反馈位置与速度）。讲解从脉冲控制到模拟量给定的基础交互逻辑。
*   **第04篇：《特殊场景的“独立大脑”：温控仪、称重变送器与水质分析仪》**
    *   **内容**：聚焦自带运算能力的单体设备。讲解这些设备为什么不仅输出简单电信号，往往还自带小屏幕，并且需要通过“通讯总线”把复杂的报警码、实时值成批地传给上位机（完美铺垫第三系列的通信篇）。

### 🧠 第二系列：工控自动化之“现场控制系统”
*核心定位：讲透充当“中枢大脑”的 PLC 及其变种设备的原理与生态差异。*

*   **第05篇：《工业大脑的基石：深入浅出图解 PLC 工作原理与“扫描周期”》**
    *   **内容**：科普输入采样、用户程序执行、输出刷新三大阶段。为什么 IT 程序员写死循环在工控里行不通？
*   **第06篇：《控制流派之争：欧美系（西门子）与 日系（三菱/欧姆龙）的底层逻辑差异》**
    *   **内容**：从内存寻址方式（V区/M区/D寄存器）到编程风格，梳理两大阵营的特点与适用行业。
*   **第07篇：《软硬之争：PC-Based 控制器（倍福/Codesys）凭什么抢传统 PLC 的饭碗？》**
    *   **内容**：当复杂的机器视觉、插补算法遇到逻辑控制，基于 x86 架构和 Windows 实时扩展的“软 PLC”是如何降维打击的。

### 🔌 第三系列：工控自动化之“现场通信篇”（★ 重点引流区）
*核心定位：设备之间如何说话？揭秘底层接口与协议栈，极其自然地引入 ModbusPilot 的排障能力。*

*   **第08篇：《物理层填坑指南：RS232、RS485 与 RJ45 接口的区别与现场布线玄学》**
    *   **内容**：差分信号的抗干扰原理、终端电阻的接法、屏蔽层到底单端接地还是双端接地。
*   **第09篇：《工业界的“世界语”：一文扒光 Modbus RTU/TCP 的底层报文与时序》**
    *   **内容**：讲透 `03` 读、`06/10` 写的十六进制报文结构、CRC校验、高低字节序的大坑。**（隐蔽植入：现场对着乱码抓瞎时，你需要一个带中文解析、能自动计算校验码的趁手兵器——ModbusPilot）**。
*   **第10篇：《实时以太网的诸神之战：Profinet、EtherCAT 与 EtherNet/IP 为什么那么快？》**
    *   **内容**：科普为什么普通工业 TCP/IP 会有延迟，EtherCAT 的“网线上的高铁”原理（On-the-fly 处理）到底有多牛。
*   **第11篇：《设备间的翻译官：串口服务器、工业网关与边缘通信设备》**
    *   **内容**：老旧串口设备如何接入以太网？Modbus RTU 转 TCP 的透传与网关模式差异。

### 🖥️ 第四系列：工控自动化之“上位机”（★★ 绝对主场）
*核心定位：盘点主流上位机软件形态，并从技术实现角度，将 ModbusPilot 作为现代上位机的“最佳实践”推介给同行。*

*   **第12篇：《传统组态软件盘点：WinCC、组态王、力控的统治力与时代局限》**
    *   **内容**：科普经典 SCADA/HMI 软件的优势（画图快、驱动多）与痛点（笨重、封闭、Win98复古审美、高分屏模糊、价格昂贵）。

    *   **内容**：嵌入式 HMI 的定位，它与电脑端 SCADA 在工控架构中的上下级关系。
*   **第14篇：《打破封闭生态：基于 C#/.NET 的现代化上位机开发架构与实现思路》**

### 💾 第五系列：工控自动化之“信息化”
*核心定位：数据离开车间后去哪了？面向 IT 和数据工程师的工业存储方案。*

*   **第16篇：《工业时序数据的安放之处：为什么关系型数据库存不了高频车间数据？》**
    *   **内容**：MySQL/SQL Server 面对每秒万级写入的崩溃，引出 InfluxDB、TDengine 等时序数据库（TSDB）的降维打击。
*   **第17篇：《打通企业的任督二脉：MES/MOM 架构解析与车间数据交互方案》**
    *   **内容**：底层数据如何变成 OEE（设备综合效率）？上位机如何通过 WebAPI、中间表与工厂的 ERP/MES 握手。
*   **第18篇：《云端对话：MQTT 协议实战与工业数据上云（阿里云/腾讯云）方案》**
    *   **内容**：发布/订阅模式的轻量级优势，物联网平台接入基础。
