## 📖 项目简介
ModbusPilot 是一款专为自动化工程师设计的现代化调试工具。它摒弃了传统工具陈旧的界面，采用 **.NET 8 (WinForms)** 构建，主打 **“轻量级组态”** 与 **“自动化流程”**。

无需安装庞大的 SCADA 系统，只需拖拽几下，即可快速搭建设备监控看板。

## ✨ 核心功能 (V0.9 Beta)
*   **多协议支持**：完美支持 Modbus RTU / TCP，支持断线重连。
*   **拖拽组态**：从资源树直接拖拽点位，生成可视化仪表盘。
*   **多主题切换**：内置 **极客黑 (Cyberpunk)**、工业灰、简约白等多种主题。
*   **双语支持**：原生支持 中文/English 实时切换。
*   **云端配置**：支持远程更新检测与配置同步。

## 📥 下载安装
本软件为绿色免安装版：
1.  进入 [发行版 (Releases)](https://gitee.com/ZerosysLab/ModbusPilot/releases) 页面。
2.  下载最新版本的 `ModbusPilot_v0.9.x_Win64.zip`。
3.  解压后双击 `ModbusPilot.exe` 即可运行。

> **注意**：如果不确定电脑是否安装了 .NET 8，请下载 **独立版 (Self-Contained)**，体积稍大但开箱即用。
